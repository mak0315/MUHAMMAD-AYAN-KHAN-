# SEO Planning Directory — Muhammad Ayan Khan Portfolio

**Status:** Planning documents only. This directory was created in Phase 1. No SEO changes have been made to `index.html`, `photography.html`, or any other live file.

## Files in this directory

| File | Purpose |
|---|---|
| `keyword-research.md` | Starting keyword list, per-page primary / secondary / long-tail keywords, and search intent. |
| `page-seo-plan.md` | Suggested titles and meta descriptions, internal linking plan, content expansion plan, and Phase 2 requirements. |

## Ground rules for this phase

- All keywords are **research starting points**, not validated data. No search volume, difficulty, or ranking claims are assumed.
- Each page gets its **own** title and meta description. Do not reuse the homepage text.
- Placeholder content in the new HTML files must be replaced with verified information before any page is published.
- No achievements, statistics, dates or credentials have been invented.
- No `sitemap.xml`, `robots.txt`, canonical tags or structured data have been added yet — these require final URL decisions.

## Phase 2 checklist (not performed here)

1. Confirm final URL paths (`/about.html`, `/startups.html`, etc.) or decide on clean URLs.
2. Add canonical tags and Open Graph tags using the confirmed URLs.
3. Replace placeholder content with verified copy.
4. Add internal links from the homepage navigation, mobile menu and footer.
5. Validate keyword targets with a keyword tool before writing final copy.
6. Add sitemap and robots files only after URLs are final.
